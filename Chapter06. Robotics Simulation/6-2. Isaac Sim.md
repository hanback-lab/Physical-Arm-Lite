# Isaac Sim

<img src="pds/isaacsim_structure.png" style="width:80%">

출처: https://developer.nvidia.com/ko-kr/blog/design-your-robot-on-hardware-in-the-loop-with-nvidia-jetson/

Isaac Sim은 NVIDIA가 제공하는 로봇 시뮬레이션 플랫폼입니다. 이는 NVIDIA Omniverse 플랫폼의 로봇 시뮬레이션용 참조 애플리케이션이며, 로봇의 모델링, 물리, 센서 시뮬레이션, 데이터 생성, ROS2 연동, 자동화까지 하나의 환경 안에서 다룰 수 있도록 구성되어 있습니다. 따라서 Isaac Sim은 단순 3D 시각화 시뮬레이션 도구가 아닌 로봇을 가상 환경에서 만들고 시험하며 실제 시스템과 연결하는 통합 개발 환경으로 이해할 수 있습니다.

이 구조를 이해하려면 NVIDIA Omniverse 구조가 무엇인지 알아야 합니다. Omniverse는 NVIDIA의 3D 애플리케이션 및 서비스 개발 플랫폼이며, 그 위에서 공통 기능을 제공하는 SDK가 Omniverse Kit 입니다. Omniverse Physics는 이 플랫폼에서 시뮬레이션을 담당하는 계층이고, Isaac Sim은 그 Physics 위에 로봇 개발에 필요한 기능을 묶어 놓은 응용 계층이라고 볼 수 있습니다. 즉 Omniverse가 기반 플랫폼, Kit이 실행과 확장 구조, Physics/PhysX가 물리 엔진, Isaac Sim이 로봇 응용 도구로 정리할 수 있으며 계층별로 개념이 구체화되는 것으로 이해할 수 있습니다.

Isaac Sim의 핵심 기반은 바로 PhysX 입니다. PhysX는 강체 운동, 충돌, 관절, 접촉 같은 로봇 시뮬레이션의 핵심 물리 계산을 담당하며, Isaac Sim은 이를 GPU 기반으로 활용해 비교적 높은 충실도의 물리 환경을 제공합니다. 또한 Isaac Sim은 카메라 및 LiDAR 등 여러 센서의 시뮬레이션을 지원하므로 단순히 로봇 관절만 움직여 보는 수준을 넘어서 인지와 제어를 함께 시험하는 환경을 만들 수 있습니다.

Omniverse 생태계에서 또 하나의 중요한 개념은 바로 OpenUSD(USD) 입니다. Isaac Sim의 장면은 USD Stage 위에 구성되며, 그 안의 객체들은 Prim 단위로 관리됩니다. 다시 말해 로봇, 센서, 바닥, 물체 같은 요소들은 USD 장면 안의 구성 요소로 다뤄지고 여기에 물리 속성이 필요할 경우 USD 물리 스키마와 PhysX 스키마가 별도로 추가됩니다. 이 구조 덕분에 장면을 계층적으로 구성하고, 자산을 재사용하고, 시뮬레이션 설정을 코드와 데이터 형태로 비교적 일관되게 다룰 수 있습니다.

## 실습 : Basic Usage

이 장에서는 간단한 Cube를 생성한 후, 물리 현상을 적용시키는 간단한 예제를 만들어봅니다. Isaac Sim을 실행하면 아무것도 없는 빈 화면, 즉 새 월드가 자동으로 생성됩니다. 전체적인 생성 방향은 다음과 같습니다.

```
Mesh 생성 -> 위치 조정 -> 물리 적용
```

먼저 물리적 충돌이 가능한 바닥을 생성합니다. 상단 좌측 툴 바에서 Create -> Physics -> Ground Plane 을 클릭하여 생성할 수 있습니다. 

<img src="pds/ground_plane_create.png" style="width:50%">

<br><br>

다음으로 간단한 큐브를 생성합니다. 상단 좌측 툴 바에서 Create -> Mesh -> Cube 를 클릭하여 생성합니다.

<img src="pds/cube_create.png" style="width:50%">

<br><br>

Isaac Sim 우측 화면에는 현재 파일에 어떤 요소들이 배치되어 있는지 나타내는 Stage 영역과 선택된 요소의 상세 설정값을 조정시켜주는 Property 영역이 존재합니다. 위 과정에서 생성한 큐브의 z 값 위치를 조정하기 위해 Stage 영역에서 'Cube' 를 클릭한 뒤, Property 역역에서 Transform -> Translate -> z 값을 '5.0' 으로 조정합니다.

<img src="pds/cube_tf_z_set.png" style="width:70%">

<br>

적용 후, 큐브의 위치가 아래 사진과 같이 바닥에서 어느정도 위로 떠오른 것을 확인할 수 있습니다.

<img src="pds/after_adjust_cube.png" style="width:60%">

<br><br>

다음으로 큐브가 물리 작용을 받게끔 설정해보겠습니다. Stage 영역에서 'Cube' 를 우클릭 한 다음 Add -> Physics -> Rigid Body with Colliders Preset 을 클릭합니다. 이 과정을 통해 Cube에 물리 작용을 설정하였는데, 추후 시뮬레이션을 실행시킬 경우 큐브가 중력 방향으로 운동하며, 다른 물체들과 충돌하는 현상을 시뮬레이션할 수 있습니다.

<img src="pds/add_rigid_cube.png" style="width:70%">

<br><br>

시뮬레이션하기 위한 모든 준비가 완료되었습니다. 시뮬레이션 좌측 'Play' 버튼을 클릭하여 시뮬레이션을 실행합니다.

<img src="pds/sim_play_space.png" style="width:50%">

<br><br>

시뮬레이션 실행 시, 위에 떠오른 큐브가 바닥으로 떨어지는 것을 확인할 수 있습니다.

<img src="pds/sim_played.png" style="width:60%">
