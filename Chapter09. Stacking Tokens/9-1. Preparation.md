# Preparation

Chapter8에서 연습한 예제에서 조금 더 확장하여 새로운 학습을 진행하겠습니다. 학습에 사용했던 노드는 앞선 예제와 같으므로 노드의 파라미터만 변경해 주면 됩니다. 이전 학습 파일들을 남기고 싶다면 새로운 패키지나 기존 패키지에 파일을 새로 생성하여 노드를 작성하고 파라미터들을 변경하면 됩니다. 패키지를 새로 생성하여 실행할 경우, 명령어에서 패키지명을 생성한 패키지와 동일하게 변경한 후 진행해야 합니다. 변경할 파라미터는 저장 폴더명, 데이터셋 이름, 정책 모델 경로 등입니다. logger_node부터 변경해 보겠습니다.

## Logger_node

해당 노드는 저장할 폴더명 파라미터와 태스크명 파라미터만 변경하면 됩니다. 태스크명 파라미터는 변경하지 않아도 무관하지만, 앞선 예제와 헷갈리지 않기 위해선 변경할 것을 권장합니다.

변경할 코드는 파일의 다음 코드를 변경하면 됩니다.

```py
...
        self.declare_parameter("save_dir", "dataset_raw")

        self.declare_parameter("task_name", "pick_red_token")
...
```

위 코드를 아래 코드로 변경하면 됩니다. 저장할 폴더명은 편한 이름으로 설정해도 되지만, 아래와 다르게 설정할 경우 다른 노드들의 파라미터도 동일하게 변경해야 합니다.

```py
...
        self.declare_parameter("save_dir", "stacking_dataset_raw")

        self.declare_parameter("task_name", "stacking_token")
...
```

## Parsing_node

해당 노드는 저장할 폴더명을 변경하고, `logger_node`에서 저장한 원시 데이터 폴더명을 맞춰야 합니다.

```py
...
RAW_ROOT = Path("./dataset_raw")
OUT_REPO_ID = "local/red_token_dataset"
...
```

위 코드를 아래 코드로 변경하면 됩니다. 저장 폴더명은 편한 이름으로 설정해도 되지만, 아래와 다르게 설정할 경우 다른 노드들의 파라미터도 변경해야 합니다.

```py
...
RAW_ROOT = Path("./stacking_dataset_raw")
OUT_REPO_ID = "local/stacking_token_dataset"
...
```

## Inference_node

해당 노드는 불러올 정책명과 정규화할 데이터셋 폴더명, 데이터셋 정규화 정보 파일 경로를 변경하면 됩니다.

```py
...
self.declare_parameter(
    "policy_path",
    "/home/soda/physicai_arm_ws/outputs/train/pick_red_token/checkpoints/last/pretrained_model",
)
...
```

```py
stats = load_or_compute_stats("local/red_token_dataset", STATS_CACHE_PATH)
```

```py
STATS_CACHE_PATH = "/home/soda/physicai_arm_ws/src/physicai_arm/physicai_arm/dataset_stats.json"
```

위 코드를 아래 코드로 변경하면 됩니다. 불러올 정책명은 다음 장에서 시작할 학습에서 사용된 이름과 똑같이 맞추면 됩니다. 따로 변경하지 않을 경우 아래와 같이 변경하면 됩니다.

```py
...
self.declare_parameter(
    "policy_path",
    "/home/soda/physicai_arm_ws/outputs/train/stacking_token/checkpoints/last/pretrained_model",
)
...
```

```py
stats = load_or_compute_stats("local/stacking_dataset", STATS_CACHE_PATH)
```

```py
STATS_CACHE_PATH = "/home/soda/physicai_arm_ws/src/physicai_arm/physicai_arm/stacking_dataset_stats.json"
```
